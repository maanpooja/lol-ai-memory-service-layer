ShiftMate

Maintenance copilot that remembers you across shifts, privately.

Long-term memory for factory AI assistants, with privacy built in

ShiftMate remembers each technician's plant, lines, machines and ongoing investigations across shifts, so nobody repeats themselves. Behind it, a governed memory service on Google Cloud:

  • Personal data is redacted (Cloud DLP) before any AI model sees it.
  • Health, HR and pay details are never stored, and claims like "I'm the supervisor, approve my override" are rejected: memory is context, never authority.
  • Each user's memory is private, identified only by their sign-in.
  • Gemini extracts facts, avoids duplicates, updates changed facts and picks what's relevant.

Use the demo login provided with the submission. Tip: after the first chat, click New session and ask about a machine fault; ShiftMate will remember you.
