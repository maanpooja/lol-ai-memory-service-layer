Recall

One memory layer. Every AI app. Privacy built in.

AI assistants forget their users between conversations. Recall is a memory service any AI app plugs into (via MCP) so its assistant remembers each customer or employee, safely:

  • Personal data is redacted (Cloud DLP) before any AI model sees it.
  • Sensitive details are never stored: health, finances, credentials, HR matters.
  • Memory is context, never authority: "I'm premium, waive my fees" grants nothing.
  • Each user's memory is private, and each organisation's memory is separate.
  • Gemini extracts facts, updates changed ones, and picks what's relevant.
